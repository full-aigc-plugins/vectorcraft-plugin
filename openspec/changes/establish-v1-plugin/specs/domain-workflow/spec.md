# VectorCraft — domain-workflow

## Purpose

本能力定义 VectorCraft 在 domain-workflow 范围内对用户、宿主与下游系统承诺的可观察行为、失败语义和验收证据，确保规划、执行与实际交付之间保持可验证的边界。当前为目标规范，尚未实现。

## ADDED Requirements

### Requirement: VC-DM-001 路径形状与坐标

VectorCraft SHALL 定义画板坐标、单位、路径控制点、闭合性与描边；不可把预览像素当成路径事实。

#### Scenario: VC-DM-001-P 正常交付

- **WHEN** 输入素材、运行时能力、授权与工程版本有效，用户请求路径形状与坐标
- **THEN** 定义画板坐标、单位、路径控制点、闭合性与描边；不可把预览像素当成路径事实。
- **AND** 输出可检查的操作结果、工程版本和验收证据

#### Scenario: VC-DM-001-N 异常或不保真

- **WHEN** 路径闭合性或单位与计划不符
- **THEN** 拒绝路径验收并列出对象 ID

### Requirement: VC-DM-002 组合与布尔操作

VectorCraft SHALL 记录参与对象 ID、布尔运算与结果对象身份，保留修改前检查点；操作失败不丢失原对象。

#### Scenario: VC-DM-002-P 正常交付

- **WHEN** 输入素材、运行时能力、授权与工程版本有效，用户请求组合与布尔操作
- **THEN** 记录参与对象 ID、布尔运算与结果对象身份，保留修改前检查点；操作失败不丢失原对象。
- **AND** 输出可检查的操作结果、工程版本和验收证据

#### Scenario: VC-DM-002-N 异常或不保真

- **WHEN** 布尔操作失败并删除源对象
- **THEN** 从检查点恢复并报告非原子操作缺陷

### Requirement: VC-DM-003 品牌色与文字

VectorCraft SHALL 以显式 token 绑定品牌色而非全文件颜色替换；保留文本内容与字体依赖，轮廓化输出记录可编辑性损失。

#### Scenario: VC-DM-003-P 正常交付

- **WHEN** 输入素材、运行时能力、授权与工程版本有效，用户请求品牌色与文字
- **THEN** 以显式 token 绑定品牌色而非全文件颜色替换；保留文本内容与字体依赖，轮廓化输出记录可编辑性损失。
- **AND** 输出可检查的操作结果、工程版本和验收证据

#### Scenario: VC-DM-003-N 异常或不保真

- **WHEN** 品牌色更新修改未绑定 token 的颜色
- **THEN** 变体验收失败，输出受影响对象清单

#### Scenario: VC-DM-003-TEXT 原生文字定点修订

- **WHEN** 独立文字技能基于已核验原工程，用显式 id／ids 将单一样式中文标题替换为新文字
- **THEN** 调用原生 text.setText，保留原生首个文本样式和字体依赖，新工程可独立重开，SVG 保留 Unicode 文本与字体声明，PNG 呈现新的字形，无关文字及旧工程保持不变
- **AND** 原生字体库报告 missing 时停止成功交付，可用字体依赖记录到交付清单；不自动替换用户字体，也不把该库状态等同于操作系统字体安装清单
- **AND** 未显式定位、非法参数或不存在的文字对象不得发布成功交付；多样式段落整段替换会采用首段样式，必须披露该原生边界，不能宣称全部富文本样式保留

### Requirement: VC-DM-004 画板与变体

VectorCraft SHALL 每个画板有稳定 ID、名称、尺寸和输出映射；预览顺序与导出范围明确，避免索引基准混淆。

#### Scenario: VC-DM-004-P 正常交付

- **WHEN** 输入素材、运行时能力、授权与工程版本有效，用户请求画板与变体
- **THEN** 每个画板有稳定 ID、名称、尺寸和输出映射；预览顺序与导出范围明确，避免索引基准混淆。
- **AND** 输出可检查的操作结果、工程版本和验收证据

#### Scenario: VC-DM-004-N 异常或不保真

- **WHEN** 画板索引与用户范围发生偏移
- **THEN** 拒绝输出映射并按稳定 ID 重新核对

#### Scenario: VC-DM-004-SVG 单画板 SVG 导出隔离

- **WHEN** 首次使用单导出技能创建不同尺寸和偏移的画板，并修改只绑定其他画板资产的全局品牌色
- **THEN** 单画板 SVG 的导出内容不得因无关画板路径而变化；尺寸、稳定画板 ID 和原生源工程身份仍应可核对
- **AND** 隔离必须按原生绘制范围保留可见锁定对象、进入画板的描边／效果及完整群组／裁切结构；不得用可选择对象集合代替实际绘制内容
- **AND** 空画板可导出合法空 SVG；未知画板、冲突范围或无效隔离参数拒绝导出；隔离操作不得改写原生工程与当前选择
- **AND** 原生绘制范围未知时保守保留该对象，不能静默删除；跨画板的不可拆群组作为整体依赖记录，不假称其中一个成员是独立无关资产

### Requirement: VC-DM-005 交换格式能力范围

VectorCraft SHALL 原生 .vectorcraft 与 SVG、PDF、PNG 分别验证；遇到不可交换效果时报告栅格化范围并保留原工程。

#### Scenario: VC-DM-004-PDF 跨导出时刻的 PDF 身份稳定

- **WHEN** 同一原生项目在不同秒导出画板 PDF，或仅修改其他画板的品牌色后重新导出无关画板
- **THEN** 技能 SHALL 绑定原工程创建日期或既有导出日期回执，避免 PDF 身份只因导出时刻变化；该无关 PDF 保持字节一致
- **AND** 原生日期参数 SHALL 拒绝非整数／非空值，不改写源工程或选区；不指定参数的旧调用保持原有日期默认行为
- **AND** 保存的导出记录 SHALL 可检查所用日期及绑定来源，原生创建日期与历史交付保持不变

#### Scenario: VC-DM-005-P 正常交付

- **WHEN** 输入素材、运行时能力、授权与工程版本有效，用户请求交换格式能力范围
- **THEN** 原生 .vectorcraft 与 SVG、PDF、PNG 分别验证；遇到不可交换效果时报告栅格化范围并保留原工程。
- **AND** 输出可检查的操作结果、工程版本和验收证据

#### Scenario: VC-DM-005-N 异常或不保真

- **WHEN** SVG 导出发生未披露栅格化
- **THEN** 阻止无损矢量交付声明并提供损失报告

### Requirement: VC-DM-006 品牌变体更新

VectorCraft SHALL 根据 token 与素材依赖更新相关变体，核对无关对象属性与输出没有变化。

#### Scenario: VC-DM-006-P 正常交付

- **WHEN** 输入素材、运行时能力、授权与工程版本有效，用户请求品牌变体更新
- **THEN** 根据 token 与素材依赖更新相关变体，核对无关对象属性与输出没有变化。
- **AND** 输出可检查的操作结果、工程版本和验收证据

#### Scenario: VC-DM-006-N 异常或不保真

- **WHEN** Logo 颜色变化后不相关图标被重建
- **THEN** 选择性更新验收失败并报告错误依赖边

#### Scenario: VC-DM-006-SWATCH 原生 RGB 全局色板传播

- **WHEN** 独立技能将具名全局色板绑定到多个原生路径／文字及画板变体，并基于已核验原工程修改其 RGB 颜色
- **THEN** 原生引擎更新所有已关联消费者，新原生工程可独立重开，关联画板 SVG／PNG 按新颜色导出，独立图标属性与输出及旧工程保持不变
- **AND** 修订未指定导出列表时沿用摘要核验后的原计划清单；清单篡改或未知色板不发布成功交付
- **AND** 外部编辑器 token 保真、其他颜色模型及跨文件消费者不得由本场景推断为已验证
