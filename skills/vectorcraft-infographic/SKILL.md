# 信息图绘制

## 任务起点

先读取素材，确认交付用途、目标尺寸或时长、修改范围与必要格式。能从任务和素材确定的细节直接采用合理默认值；只询问会改变结果的缺失条件。

需要可见编辑器时交给 **vectorcraft-editor** 技能。独立安装：`npx skills add full-aigc-skills/vectorcraft-skills --skill vectorcraft-editor`。当前新增技能为本地候选，发布前使用本地配套插件，不把此安装命令当作已发布证明。

## 执行步骤

1. 先确认信息顺序与数据来源，再选择流程、对比或分组结构。
2. 构造统一节点和连接线，按阅读方向组织内容。
3. 将数字与单位保留为可编辑文字，颜色表达固定类别。
4. 检查连线、标签与图例后导出。

## 工具落地

用 open_file/run_command 管理图形，inspect_document 检查对象；draw_shape 或 run_command 编辑，save_file 保存，screenshot 查看。

先读取实际工具 schema，再填写参数；对象或文档 ID 使用返回值。查询到的命令必须在当前后端可用。保存前选择新输出路径，保留输入。需要的算法、格式或命令不存在时说明缺口，不能用相近名称冒充。

## 结果检查

- 数据编码不夸大差异。
- 连线不穿过标签，箭头方向与流程一致。
- 源文件内对象可独立编辑。

对照用户目标检查实际内容，而不只检查进程退出码。局部编辑查看局部细节，版式任务查看整页，时间媒体查看起止与关键段。异常结果先检查当前工程，避免重复执行不可逆操作。

## 交付

返回可编辑工程、实际派生文件和简短说明：做了哪些修改、哪些步骤因当前能力未执行、需要用户判断的内容。只列真实存在且已经检查的文件。若用户随后返工，读取本次源工程并局部修改，保留已接受的内容。
