# 场景技能候选

新增技能位于 skills/，独立技能源维护，插件本地候选按 scenario-candidates.json 校验。既有发布快照不变。当前完成内容与实际场景视觉验收分开；尚未逐场景完成用户素材验收。

- `vectorcraft-logo-system`：标志与变体（矢量标志、单色版与反白版）
- `vectorcraft-icon-set`：统一图标集（同风格矢量图标）
- `vectorcraft-infographic`：信息图绘制（流程、结构和数据说明图）
- `vectorcraft-trace-artwork`：位图转矢量整理（标识和线稿矢量重建）
- `vectorcraft-editable-chart`：可编辑图表（报告中的矢量图表）
- `vectorcraft-svg-cleanup`：SVG 交付整理（SVG 尺寸、路径与兼容性）
