# VectorCraft 布尔几何首次使用验收

固定 VectorCraft 插件 dev.8／技能源 dev.7，复制已安装的 `vectorcraft-cli-boolean` 到独立 `.agents/skills/`，从空运行目录默认下载 CLI 0.2.0。一个技能完成原生操作与 SVG、PNG、PDF 导出，没有读取兄弟技能。

测试矩形外轮廓与内轮廓的并集、减去前方、交集、排除。减去前方与排除保存为 `NonZero` 复合路径：两个闭合轮廓的方向相反，面积分别为 6400 与 1024，中心保持透明。并集保留中心，交集只保留内轮廓。独立原生会话重新打开保存工程取得几何。

PNG 直接解码；SVG 与 PDF 使用现有 PyMuPDF 独立渲染，分别检查外轮廓、中心、外部与未参与运算图形。SVG 没有 image 节点，PDF 有矢量绘制且没有栅格图像。无关图形原生属性保留；每项修订后原交付目录所有文件摘要一致。无效选择失败且不发布新交付目录。12 项已安装技能摘要与原宿主回执保持一致。

实际目标测试 1 项通过，包含四个正向运算和无效选择拒绝，9.625 秒；源码默认回归 43 项中 28 通过、15 项 opt-in 跳过。跳过项不作为验收通过。见 [证据](evidence/codex-vectorcraft8-boolean-geometry-first-use-20261006.json)。

原始测试将孔洞结果误认成单路径，原生回执表明实际是复合路径；断言已按真实结构改为检查闭合性、面积、方向及真实透明输出，没有修改产品代码。任意曲线／自交几何、divide／trim、外部编辑器往返、GUI／模型和完整创作验收不由这些矩形样例推断。
